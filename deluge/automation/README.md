# The automation layer

A workflow rule's **Function** action can only pick a function whose category is
`automation`. An `automation` function cannot be called from another function, and
`standalone` is the only category that can be. The two categories therefore do
different jobs, and the adapter between them is kept deliberately thin: every line of
real logic lives in the standalone library under `../crm`, which is the part worth
testing and reusing. These eleven functions exist only to be the entry point of
exactly one workflow rule each.

Generated by `tools/make_automation.py`; deployed with the same POST-then-PUT flow as
the standalone library.

| Module | Trigger | Adapter | Call |
|---|---|---|---|
| Leads | Edit | `wfConfirmAdmission` | `}` |
| Academic_Years | Create or Edit | `wfEnforceSingleCurrentYear` | `}` |
| Attendance | Create | `wfAttendanceCreated` | `standalone.attendanceRollupFromRecord(attendanceId, "create");` |
| Attendance | Edit | `wfAttendanceEdited` | `standalone.attendanceRollupFromRecord(attendanceId, "edit");` |
| Marks | Create or Edit | `wfValidateMark` | `standalone.validateMark(markId);` |
| Examinations | Edit | `wfPublishExamResults` | `}` |
| Payments | Create | `wfPaymentCreated` | `standalone.generateReceipt(paymentId);` |
| Payments | Edit | `wfPaymentEdited` | `standalone.allocatePayment(paymentId);` |
| Students | Create or Edit | `wfInvalidatePortalCache` | `standalone.invalidatePortalCache(studentId);` |
| Leave_Requests | Edit | `wfProcessLeaveApproval` | `}` |

## Scheduled functions

A Schedule can only pick a function whose category is `schedule`, so these are
adapters too.

| Runs | Adapter | Calls | Why |
|---|---|---|---|
| daily 11:00 | `schAbsenceSameDay` | `standalone.notifyAbsenceSameDay()` | Same-day absence alert to parents |
| daily 08:00 | `schFeeDueSweep` | `standalone.feeDueScheduler()` | Fee due and overdue sweep |
| daily 02:00 | `schEarlyWarning` | `standalone.runEarlyWarning()` | Nightly early-warning engine |
| daily 01:00 | `schReconcileAttendance` | `standalone.reconcileAttendance()` | Attendance rollup reconciliation |
